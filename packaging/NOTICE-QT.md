# Qt в Mohr Frame

Интерфейс Mohr Frame v0.9.0 использует динамические библиотеки Qt Core,
Qt Gui и Qt Widgets версии 6.8.3. Эти библиотеки распространяются на
условиях GNU LGPL версии 3. Текст лицензии находится рядом с этим файлом:
`LGPL-3.0.txt`.

Исходный код Qt 6.8.3 доступен в официальном архиве:
https://download.qt.io/official_releases/qt/6.8/6.8.3/single/

Пользователь может заменить поставляемые библиотеки Qt совместимыми
собственными сборками. Приложение связывается с Qt динамически; Rust-ядро
и C++-код приложения распространяются по лицензии MIT (см. `LICENSE`).
Сведения о стороннем коде, входящем в Qt, опубликованы Qt:
https://doc.qt.io/qt-6.8/licenses-used-in-qt.html
