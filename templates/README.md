# Табличный импорт Mohr Frame

`mohr-input.xlsx` и папка `csv/` содержат одинаковый пример. Для своего проекта используйте один файл XLSX с листами ниже или одну папку с CSV-файлами с теми же именами (`Points.csv`, `Rods.csv` и т. д.). Обязательны только `Points` и `Rods`; остальные таблицы можно убрать. Первая строка каждого листа или файла — названия столбцов на латинице. Разделитель CSV — запятая, кодировка UTF-8. Каждый импорт создаёт новую модель целиком после проверки и подтверждения.

| Таблица | Столбцы | Смысл |
|---|---|---|
| `Points` | `id,x,y` | Имена узлов и координаты |
| `Rods` | `id,start,end,h,ei_preset,alpha_preset,hinge_start,hinge_end,t_upper,t_lower` | Стержни, высота сечения, ссылки на строки свойств, концевые шарниры и температуры |
| `EI`, `Alpha` | `id,name,numeric,factor,mantissa,exponent` | Независимые наборы EI и α; `numeric=0`: `factor·EI` / `factor·α`; `numeric=1`: `mantissa·10^exponent` |
| `Supports` | `node,kind,normal_deg,dx,dy,dphi,dn` | Тип опоры и заданные смещения по X, Y, повороту и нормали |
| `NodeLoads` | `node,fx,fy,mz` | Сосредоточенные узловые силы и момент |
| `MemberLoads` | `rod,qx,qy,ea,ei` | Равномерные нагрузки по глобальным X/Y и численные жёсткости МКЭ; `0` означает аналитическое значение |
| `PointLoads` | `rod,xi,fx,fy,mz` | Сосредоточенные воздействия на стержне, `xi=x/L` от 0 до 1 |
| `Diagrams` | `rod,field,kind,left,left_side,right,right_side,q,q_side,has_extremum` | Ручные грузовые и единичные эпюры |
| `Settings` | `key,value` | Дополнительные параметры проекта из примера |

В `Supports.kind` допустимы `free`, `fixed`, `pin`, `roller`, `guided`. Угол нормали `normal_deg` отсчитывается от глобальной оси X в градусах. Для эпюр тип `kind` — `constant`, `linear` или `parabolic`. Поле `field`: `m`, `n`, `q`, `mx`, `my`, `mphi`, `nx`, `ny`, `nphi`. Значения `left` и `right` вводятся как модули; стороны `left_side`, `right_side`, `q_side` задаются `+` (низ/право), `-` (верх/лево) или `axis` для нулевой ординаты. Для параболы `q` — модуль кривизны, направление задаёт `q_side`. `has_extremum` принимает `0` или `1`.

Координаты, длины, силы, моменты, температуры и жёсткости вводите в **согласованной системе единиц**. Пример использует метры, кН, кН·м и °C; автоматического перевода единиц нет. Пустое обязательное поле вызывает ошибку с указанием таблицы, строки и столбца. Для необязательных полей применяются явно заданные в модели значения по умолчанию. Десятичная запятая поддерживается в XLSX и в кавычках CSV (`"0,5"`); обычная запятая в CSV разделяет столбцы. Формулы XLSX допустимы только с сохранённым вычисленным значением: откройте и сохраните книгу в редакторе таблиц после пересчёта. Формула без кешированного результата выдаст ошибку.

Открывайте **Проект → Импорт Excel…** или **Проект → Импорт CSV…**. В окне предварительного просмотра проверьте количество объектов и точки, затем подтвердите замену текущей модели. При ошибке исходный проект не меняется.
