# mohr-frame

Нативная графическая программа на Rust для расчёта перемещений точек плоской
стержневой рамы методом Мора (перемножением эпюр). Сначала задаются точки,
затем стержни между ними. Геометрия, грузовая эпюра `Mp`, единичные эпюры
`mx`/`my` и результаты `Δx`/`Δy` обновляются сразу при изменении параметров.
Для каждого стержня независимо задаётся коэффициент жесткости относительно
базового `EI`, например `1·EI`, `2·EI` или `0,5·EI`.

Рабочее пространство разделено на четыре вкладки: схема и эпюры `M`, `N`,
`Q`; силовое перемещение; температурное перемещение; кинематическое
перемещение. Температурная и кинематическая вкладки пока являются
подготовленными заглушками.

Программа формирует подробный отчёт Microsoft Word (`*.docx`) без внешних
рантаймов. В отчёт включаются геометрия, таблицы эпюр, расчётная схема с
размерными засечками и развёрнутые подстановки по каждому стержню. Нулевые
вклады не отбрасываются и явно присутствуют в суммах для `Δx` и `Δy`.

## Принятая система знаков

Эпюры строятся на растянутых волокнах. Каждая ненулевая ордината вводится
как модуль и сторона:

- верхние волокна горизонтального / левые волокна вертикального стержня — `−`;
- нижние волокна горизонтального / правые волокна вертикального стержня — `+`.

Для наклонного стержня «лево/право» понимается относительно локальной оси,
направленной от начальной точки к конечной. Сторона выпуклости параболы
задаёт знак добавки `q·L²/8` к полусумме концевых ординат.

Если хотя бы одна эпюра на участке параболическая, используется заданная
трёхточечная формула Симпсона. Для двух линейных/постоянных эпюр применяется
аналитическая формула перемножения трапеций.

> Важно: трёхточечная формула Симпсона точна, когда произведение эпюр имеет
> степень не выше третьей. Если обе эпюры параболические, их произведение
> имеет четвёртую степень, поэтому результат является принятой условиями
> задачи трёхточечной аппроксимацией.

## Сборка и запуск

Требуется стабильный Rust toolchain: <https://rustup.rs/>.

### macOS

```bash
chmod +x scripts/bundle-macos.sh
./scripts/bundle-macos.sh
open "dist/Mohr Frame.app"
```

Готовое приложение будет находиться в `dist/Mohr Frame.app`. Его можно
запускать двойным щелчком как обычную программу macOS. Отдельный бинарный
файл также находится в `target/release/mohr-frame`.

### Windows (PowerShell или cmd)

```powershell
cargo build --release
.\target\release\mohr-frame.exe
```

Бинарный файл будет находиться в `target\release\mohr-frame.exe`.

После сборки приложение не требует установки Rust на целевом компьютере.
Для каждой ОС бинарный файл нужно собирать под соответствующую целевую
платформу (локально или через CI).

## Работа с программой

- слева создаются точки с координатами, затем стержни между выбранными точками;
- длина и расположение стержня вычисляются автоматически по координатам;
- выбирается точка, горизонтальное и вертикальное перемещения которой нужны;
- для каждого стержня задаются `Mp`, `mx` и `my`;
- для каждого стержня задаётся его жесткость `EI участка = k·EI`;
- проект сохраняется в переносимый файл `*.mohr.ron` рядом с приложением;
- при открытии восстанавливаются геометрия, жесткости и все эпюры;
- кнопка `Экспорт Word` создаёт рядом с проектом подробный файл
  `<имя проекта>-report.docx`;
- кнопка `Очистить схему` после подтверждения удаляет с рабочего полотна все
  точки, стержни и эпюры, но не удаляет сохранённые файлы;
- справа одновременно показаны рама, `Mp`, `mx` и `my`;
- на вкладке силового перемещения размеры показаны шрифтом OpenGost Type A и
  размерными засечками без стрелочных наконечников;
- результаты выводятся отдельно как `Δx` и `Δy`;
- состояние автоматически сохраняется между запусками;
- числовые поля можно менять вводом или перетаскиванием мыши.

`mx` — эпюра от единичной горизонтальной силы в выбранной точке, `my` — от
единичной вертикальной силы. Выбор точки сам по себе не строит единичные эпюры:
они вводятся пользователем согласно единичным состояниям расчетной схемы.

Шрифт OpenGost Type A распространяется по лицензии SIL Open Font License 1.1;
текст лицензии находится в `assets/OpenGost-LICENSE.txt`.

Для запуска из исходников и проверки:

```bash
cargo run --release
cargo test
```

## Структура проекта

- `src/lib.rs` — узловая модель (`Node`, `Rod`, `StructuralModel`) и расчёт;
- `src/main.rs` — графический редактор и живое отображение эпюр;
- `draw_frame_ascii()` — текстовое представление геометрии и обеих эпюр.
